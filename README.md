# Thala 7 Sneaker Store - CSS Mini Project

## Overview
A complete front-end sneaker eCommerce web application built strictly with HTML and pure CSS (utilizing Flexbox) without external CSS frameworks like Bootstrap.

## Implemented Pages
1. **Landing Page (`index.html`)**:
   - Header with Logo, Navigation Links, Search input, Cart icon, and Profile image.
   - Two-column Hero section highlighting "7!! Thala For a Reason!" alongside the flagship sneaker.
   - Full-width Service Overview section displaying live trust metrics (2k+ Reviews, 30k+ Customers, High Quality, 4.5/5 Rating).

2. **Product Display Page (`product.html`)**:
   - Breadcrumb navigation.
   - Main shoe view with description, pricing, discount badge, quantity counter, and "Add to Cart" CTA.
   - Bottom horizontal scrolling gallery showcasing thumbnail shoe variants.

3. **Shopping Cart View (`cart.html`)**:
   - Itemized product table displaying thumbnails, dynamic quantity controls, price tags, and remove actions.
   - Coupon application card.
   - Comprehensive calculation summary (Sub Total, Taxes, Discounts, Total).
   - "Continue Shopping" navigation link and verified trust badges.

4. **Payment Page (`payment.html`)**:
   - Customer Email ID capture field.
   - Tabbed payment method selector (Cards, Crypto, Net Banking).
   - Card information fields (Card Number, Expiry, CVV, Country, Zip Code).
   - Synchronized Order Summary and "Pay Now" checkout button.
